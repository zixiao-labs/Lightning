# Get started with Lightning

Lightning is a Nasti-native test runner for Node.js, DOM emulators, and real
browsers. It runs TypeScript, JSX, and ESM through Nasti's module pipeline.
Its Vitest 5.0.3 compatibility covers a supported API subset, not every
Vitest or Jest feature.

## Install and run your first test

Use Node.js 22.12.0 or newer. In your project, install Lightning as a development
dependency:

```sh
pnpm add -D @lightning-js/lightning
```

Create `sum.test.ts` in your project:

```ts
import { expect, test } from "@lightning-js/lightning";

test("adds two numbers", () => {
  expect(2 + 3).toBe(5);
});
```

Run the suite once, filter by filename, or rerun as you edit:

```sh
pnpm exec lightning run
pnpm exec lightning run sum.test.ts
pnpm exec lightning watch
```

Use `run` in CI. Without a subcommand or an explicit `--watch` or `--no-watch`
flag, Lightning watches when standard input is a terminal (TTY) and runs once
otherwise.

## Choose where tests run

| Use case | What to run |
| --- | --- |
| Pure functions, servers, or Node.js modules | Start with the default `node` environment. |
| Components that need a DOM but not a browser engine | Install `jsdom` or `happy-dom` and select it with `test.environment`. |
| Browser-specific behavior or trusted browser input | Install Playwright and the browser binary, then run with `--browser`. Always await `userEvent` interactions. |

Set defaults in `lightning.config.ts` with `defineConfig` from
`@lightning-js/lightning/config`. For a repository with both Node.js and DOM
tests, use `test.projects` to give each group its own environment.
