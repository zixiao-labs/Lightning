# Lightning v3.1.0

发布日期：2026-10-04。本次新增 Vitest 风格的测试阶段耗时摘要。

## 更新内容

- 默认终端摘要新增 transform、setup、import、tests 和 environment 阶段耗时。
- 新增公开 `DurationBreakdown` 类型，并在 `FileResult` 和 `RunSummary` 中提供可选的 `durationBreakdown`。
- 阶段耗时为累计值；阶段之间可能重叠，并行执行时各阶段耗时之和可能超过总墙钟时间。

## 升级说明

无需迁移。新增结果字段为可选；自定义 reporter 可以忽略它。默认终端摘要会多显示阶段耗时。

## 验证

- Node 24.15.0：`pnpm install --frozen-lockfile`、`pnpm typecheck`、`pnpm test` 通过。
- forks pool、playground、runtime、CLI/文档集成、frameworks、类型及基准测试通过；基准 playground 按设计跳过 1 项。
- Chromium 浏览器集成通过（4 项）。
